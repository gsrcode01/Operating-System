Writer-Preference Logic 
public synchronized void startRead() throws InterruptedException {
    // Wait if a writer is active OR any writer is waiting!
    while (writerActive || waitingWriters > 0) {
        wait();
    }
    readers++;
}

public synchronized void startWrite() throws InterruptedException {
    waitingWriters++;
    try {
        while (writerActive || readers > 0) {
            wait();
        }
        writerActive = true;
    } finally {
        waitingWriters--;
    }
}
💡 Writer Preference: In startRead(), readers check waitingWriters > 0. Even if a reader is already reading, newly arriving readers are blocked as soon as a writer expresses intent to write. Once current readers exit, the waiting writer gets priority, eliminating writer starvation!

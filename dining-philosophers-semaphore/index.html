// Centralized FIFO Scheduler guarantees deadlock-freedom
static void schedule() {
    Iterator<Integer> it = waiting.iterator();
    while (it.hasNext()) {
        int p = it.next();
        if (canEat(p)) {
            chopstickBusy[left(p)] = true;
            chopstickBusy[right(p)] = true;
            granted[p] = true;
            it.remove();
            wakeup[p].release(); // Wake up blocked thread
        }
    }
}
💡 How Deadlock & Starvation Are Avoided: Neither philosopher picks up only one chopstick. A philosopher either receives both chopsticks atomically from the scheduler or sleeps on their dedicated wakeup[p] semaphore. The FIFO waiting list ensures fairness and completely prevents starvation.

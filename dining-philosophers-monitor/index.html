public synchronized void takeChopsticks(int p) throws InterruptedException {
    waiting.addLast(p);
    schedule();
    while (!granted[p]) {
        wait(); // Released monitor lock & sleeps
    }
}

public synchronized void putChopsticks(int p) {
    chopstickBusy[left(p)] = false;
    chopstickBusy[right(p)] = false;
    granted[p] = false;
    schedule(); // Calls notifyAll() internally
}
💡 Monitor Design: Java monitors encapsulate mutual exclusion through synchronized methods. When a hungry philosopher cannot eat because chopsticks are busy, they enter the condition wait set with wait(), releasing the monitor. When any chopsticks are freed, notifyAll() awakens waiting threads to recheck their canEat() condition.
